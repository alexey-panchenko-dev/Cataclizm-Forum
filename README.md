# После катастрофы

Сайт с информацией о крупных катастрофах и историями людей, которые их пережили.

## Возможности

- регистрация и сохранение профиля в `localStorage`;
- добавление собственных событий;
- поиск и фильтрация каталога;
- комментарии на страницах событий;
- история комментариев в профиле;
- добавление материалов поддержки и запросов о помощи;
- сохранение пользовательских данных через Zustand.
- редактирование профиля и удаление собственных записей;
- светлая и тёмная темы;
- адаптивный интерфейс для компьютеров и телефонов.

## Запуск

```bash
npm install
npm run dev
```

Проект откроется по адресу `http://localhost:3000`.

## Структура проекта

```text
src/
├── app/       запуск приложения, роутер и глобальные стили
├── pages/     страницы сайта
├── widgets/   крупные общие блоки: шапка и подвал
├── entities/  данные, типы и карточка события
└── shared/    общая конфигурация и переиспользуемые компоненты
```

Структура следует основным принципам FSD, но без лишних уровней и файлов-посредников.
